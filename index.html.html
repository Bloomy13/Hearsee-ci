Step-by-step guide to publishing the Hearsee competitive intelligence dashboard on GitHub Pages — a free permanent URL your team can bookmark

What you'll end up with
A permanent, shareable URL for your team
https://your-username.github.io/hearsee-ci/
Free forever · No login required to view · Works on any device · Update anytime
Setup — about 15 minutes
1
Create a free GitHub account
Go to github.com and sign up. Choose any username — it becomes part of your URL, so something like hearseemobility works well.
Already have GitHub? Skip to step 2.
2
Create a new repository
Once logged in, click the green "New" button on your dashboard. Fill in the form:
Repository name: hearsee-ci
Set to Public (required for free GitHub Pages)
Check "Add a README file"
Click Create repository
3
Upload the dashboard file
Inside your new repository, click "Add file" → "Upload files". Drag and drop the Hearsee_Competitive_Intelligence.html file you downloaded earlier. Then — this is important — rename it before uploading:
Rename the file to index.html before uploading. GitHub Pages automatically serves a file named index.html as the homepage. If you upload it with the original name, your URL will have the full filename in it.
index.html
Add a commit message like "Add competitive intelligence dashboard" and click Commit changes.
4
Enable GitHub Pages
In your repository, click Settings (top menu) → scroll down to Pages in the left sidebar.
Under "Source" select Deploy from a branch
Branch: select main
Folder: select / (root)
Click Save
5
Wait 2–3 minutes, then visit your URL
GitHub builds and publishes your site. After a couple of minutes, go to:
https://your-username.github.io/hearsee-ci/
Replace your-username with your actual GitHub username. The dashboard will be live and fully functional.
The Pages section in Settings will show you the exact URL once it's published — look for the green "Your site is live at…" message.
6
Share with your team
Copy the URL and send it via email, Slack, or Teams. Anyone with the link can open the full dashboard — no GitHub account, no login, no install.
